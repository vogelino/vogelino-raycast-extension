# Vogelino Cool Sites

Browse, search, and add cool sites featured on the Vogelino portfolio.

## Setup

The extension needs a GitHub personal access token that can trigger repository dispatch events for
`vogelino/vogelino-portfolio`. Add the token in Raycast Preferences under **Vogelino Cool Sites**.

The **Add Cool Site** command pre-fills the current Arc tab when Arc is running. You can always enter the name and URL
manually.

## Commands

- **Search Cool Sites** browses and filters the portfolio's cool-site collection.
- **Add Cool Site** dispatches the portfolio update workflow with a name, URL, and tags.
